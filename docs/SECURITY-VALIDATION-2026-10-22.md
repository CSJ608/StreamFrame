## 红绿证据与失败归因

- Windows 监听独占回归：原实现 12 项失败（复用竞争绑定和选项），修复后新增 24 项在三框架通过；Linux 保留复用语义，不宣称同样提供 Windows 独占保护。
- 重连发布回归：原实现新增 8 项中 6 失败、2 通过；修复后新增 9 项与加强后的 Wedge 在三框架各 10/10 通过。
- 原 Wedge 握手探针可能落入旧监听器 backlog，并把旧 Connected 状态当成自己的新会话。已用确定性测试证明，现要求新编号、双向报文及旧会话终止，未放宽预算。
- 状态序列测试原先等待 State 快路径，可能在锁外事件尚未记录前断言；现等待事件记录信号，原精确序列不变。
- 初次 Linux 运行失败是 Windows xUnit apphost 无法在 Linux 启动，已改用 Linux 原生构建，不混用产物。
- 初次跨平台 locked restore 发现测试 RID 与 AOT 隐式版本不同；已显式固定 RID 集合并用 SDK 10.0.402 重新生成、双平台复验。
- AOT 容器缺链接器/旧缓存路径已在一次性容器补齐并强制恢复，不修改系统环境。
